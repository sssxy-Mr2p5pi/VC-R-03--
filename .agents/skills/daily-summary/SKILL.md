在项目根目录使用 `.venv\Scripts\python.exe`。本技能只整理**已经发生**的工作，不生成未发生的证据。
项目外的素材目录为 `..\VC-R-03-学习指南\`，其中 `纠偏记录.md` 与 `中期报告素材（不提交）\` 均**不进入 Git，也不进入课程提交包**。

1. 先取真实时间（北京时间）。若已过零点但仍在同一次连续工作会话内，按会话开始日归属，并在正文里注明。
2. 读取 `每日工作记录/<日期>/今天做了什么.md`、当天真实 Git 提交（`git log --all --date=iso`）和本轮实际动作，确认哪些事真的发生过。
3. 把当天记录压到 5～8 条，第一人称口语体，仿样例 `2026-10-14\今天做了什么.md` 的写法。**数据实测细节、规则条文不要堆在这里**，它们另有去处。
4. 当天新增的数据实测搬到 `evidence/data/`（新建或更新计数文件）。每条必须写明：统计口径、覆盖范围（哪张工作表／哪些行）、实际结果、实测日期。只覆盖部分数据时要显式写出范围。
5. 当天新增的业务或流程决定写进 `决定记录.md`，每条含**日期／决定／备选／理由**；尚未拍板的标"待确认"，不冒充已经拍板。
6. 当天发现的错误与纠偏追加到 `..\VC-R-03-学习指南\纠偏记录.md`，每条含**日期／语境／错误（含卡在哪一层）／我的做法**。
7. 把当天产生的报告可用素材同步到 `..\VC-R-03-学习指南\中期报告素材（不提交）\` 的对应分节文件：数字与来源进相关节，失败与修复进 `07-问题与解决.md`，用量进 `08-成本统计.md`，计划与日期进 `09-遗留问题与计划.md`。该目录只是素材仓库，**最终报告才提交**。
8. 运行 `scripts/save_daily_log.py` 导出当天提交记录。**不要用 `--note` 代替人工核对**；脚本只导出真实 Git 历史。
9. 登记当天 token 用量与费用（报告第八节要汇总）。两个工具单位不同就分开写，取不到就写"未取得"并写明原因，不估算。
10. 提醒本人补充当天截图（终端输出、界面、报错与纠偏画面）。没有实际截图时如实标注缺失，**不生成也不照抄图片**。
11. 回报：当天条目数、新增决定编号、新增纠偏编号、缺失项，以及规格／报告／PPT 需要同步的地方。

引用教材原文时回到课程原件核对，不凭记忆引用。业务口径未定时（两边数据、非商品行处置、切片范围）先问用户，不在本技能中自行决定。
